# Analisi dei requisiti (RAD)

**Già stabilito.** Questa cartella ospita il Requirements Analysis Document (RAD). Il team consulta il RAD approvato per capire quali requisiti deve soddisfare il prodotto e per verificare che i deliverable siano coerenti con tali requisiti.

**Per GitHub Copilot.** Nel lavoro sui requisiti, basarsi sul RAD e sui requisiti effettivamente approvati. Segnalare lacune o incongruenze, come indicato in [AGENTS.md](../../AGENTS.md).

**Indicazione proposta.** Quando un documento richiama un requisito, indicare il punto del RAD in cui è descritto per facilitarne la verifica.
